The upstream skill collection is preserved under reference/upstream-skills with attribution. Some reference workflows mention optional integrations and schedules; those are not installed or claimed active. This distribution's active maintenance procedure is self-contained. The optional context hook uses bounded lexical matching, not embeddings; session continuity depends on the assistant writing its handoff. There is no always-running process or automatic cloud backup.

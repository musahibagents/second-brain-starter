# /research — Research an entity or topic

Target: **$ARGUMENTS**.

Search existing pages and aliases before external research. Extend the canonical record. Define the decision this research supports. For people establish role and decision authority; for companies examine operating process, observable tools and recent triggers; for a field examine current practice, alternatives and unresolved problems. Cite original sources with publication/access dates. Separate evidence from inference and show arithmetic for cost estimates. Where no evidence supports a number, state the unknown and the question that would resolve it. Present the useful opportunity and reasons it may be a poor fit. File by primary subject and apply notability and enrichment gates. Create a board entry only for a real active opportunity.


Use the installed owner profile and chosen assistant identity. Search before creating pages. Follow `_system/conventions/filing.md`, `_system/conventions/source-attribution.md` and `_system/doctrine/completion-status.md`. Create task output folders only when needed. Referenced account records and banks are optional evidence, not assumed facts. Drafting never grants permission to send or publish.

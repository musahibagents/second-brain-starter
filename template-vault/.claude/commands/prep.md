# /prep — Prepare for a call

Target: **$ARGUMENTS**.

Search the account, people, dated call records, board and any existing offer or objection notes. Produce a short call card: attendees and decision authority; actual stage and value; last interaction; commitments owed by each side; the buyer’s stated needs; three to five unanswered questions; likely objections with sourced responses; the main risk; one desired outcome with a date. Quote only exact available wording. Label judgments observed, self-described or inferred. Do not change deal status from preparation. End with the next debrief step.


Use the installed owner profile and chosen assistant identity. Search before creating pages. Follow `_system/conventions/filing.md`, `_system/conventions/source-attribution.md` and `_system/doctrine/completion-status.md`. Create task output folders only when needed. Referenced account records and banks are optional evidence, not assumed facts. Drafting never grants permission to send or publish.

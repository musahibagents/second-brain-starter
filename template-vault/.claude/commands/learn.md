# /learn — Extract durable lessons

Target: **$ARGUMENTS**.

Read the relevant project, journal, outcomes and prior patterns; scope the review to the request. Examine responses that changed outcomes, communication preferences, successful approaches, recurring failure stages and gaps between stated priorities and recorded activity. Three independent dated instances are the default minimum for a pattern; fewer are explicit watch items. Keep instance counts, sources, counterexamples and last-confirmed dates. Never turn hearsay or one vivid event into a personality judgment. Update or create _system/patterns.md as a sourced synthesis and append its evidence log. Supersede contradicted conclusions while preserving evidence. Promote only operational rules to memory. Lead with one useful behavior change and state evidence limits.


Use the installed owner profile and chosen assistant identity. Search before creating pages. Follow `_system/conventions/filing.md`, `_system/conventions/source-attribution.md` and `_system/doctrine/completion-status.md`. Create task output folders only when needed. Referenced account records and banks are optional evidence, not assumed facts. Drafting never grants permission to send or publish.

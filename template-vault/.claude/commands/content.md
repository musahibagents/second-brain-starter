# /content — Draft evidence-based content

Target: **$ARGUMENTS**.

Read the owner’s profile, recent work, existing content and measured outcomes. Select a topic supported by real work; if no topic is given suggest up to three evidenced angles. Use the owner’s preferred voice. Explain what happened, the mechanism and the supported outcome. Where useful specify the screenshot or illustration to capture. Check permission before identifying clients or sharing internal figures; use anonymous examples when permission is absent. Distinguish concepts from working products. Avoid invented metrics and engagement bait. Save one canonical post file under strategy/Content with draft versions and capture instructions. Publication and metrics are recorded only after evidence of each.


Use the installed owner profile and chosen assistant identity. Search before creating pages. Follow `_system/conventions/filing.md`, `_system/conventions/source-attribution.md` and `_system/doctrine/completion-status.md`. Create task output folders only when needed. Referenced account records and banks are optional evidence, not assumed facts. Drafting never grants permission to send or publish.

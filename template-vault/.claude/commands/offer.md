# /offer — Draft an offer

Target: **$ARGUMENTS**.

Read the buyer’s needs, constraints, evidence, commitments and any existing offer/objection records. Write the specific problem, desired outcome, proposed scope, proof, assumptions, exclusions, likely objections and a single next step. Reuse prior pricing only if genuinely comparable and explicitly approved for this offer; otherwise mark pricing unresolved. Estimates need a stated basis and assumptions. Do not invent delivery promises. Scope reductions accompany any discount proposal. Save the draft under strategy/Offers and link it from the account. Only confirmed sending changes the stage to proposal sent; only confirmed payment counts as cash. Reusable patterns may be recorded without client particulars.


Use the installed owner profile and chosen assistant identity. Search before creating pages. Follow `_system/conventions/filing.md`, `_system/conventions/source-attribution.md` and `_system/doctrine/completion-status.md`. Create task output folders only when needed. Referenced account records and banks are optional evidence, not assumed facts. Drafting never grants permission to send or publish.

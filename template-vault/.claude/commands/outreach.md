# /outreach — Prepare an outreach batch

Target: **$ARGUMENTS**.

Read the owner’s active outreach policy and contact register if configured; report their absence and use draft-only preparation. Verify each contact’s full name, company, role, intended address/handle and specific relevance trigger with evidence. Hold unverified contacts separately and report counts and reasons. Cross-check existing relationships and prior sends to avoid duplicate or cold messaging of active conversations. Draft short, individual messages with an observed trigger, one supported claim and one appropriate next step. Follow the owner’s channel policy; do not assume a sequence is authorized. Draft any agreed follow-ups with proposed dates and new substance. File the batch under strategy/Outreach; cold list entries do not automatically merit person pages. On substantive reply apply notability, create/update the entity and track a dated next action.


Use the installed owner profile and chosen assistant identity. Search before creating pages. Follow `_system/conventions/filing.md`, `_system/conventions/source-attribution.md` and `_system/doctrine/completion-status.md`. Create task output folders only when needed. Referenced account records and banks are optional evidence, not assumed facts. Drafting never grants permission to send or publish.

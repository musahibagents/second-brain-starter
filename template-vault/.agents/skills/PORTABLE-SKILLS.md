# Portable specialized skills

Website delivery and Unslop are active local skills. The three shared design documents are in `Design/00 Framework/`. Unslop scripts require Node.js and Playwright; the optional story renderer also requires ffmpeg. Install runtime dependencies only when needed for authorized work.

The nine Strix security workflows are preserved with their Apache-2.0 license metadata and usestrix attribution. They require separately installed Strix tooling, an authorized target, and the user's own provider/account access. Read `penetration-testing-with-strix/SKILL.md` for setup. No scans, paid services, keys, containers or cloud accounts are installed by this vault installer. Verify current tool flags and pricing before execution.

Unslop retains its CC BY 4.0 license, source record, reference images and scripts. Reference images are upstream examples rather than the original vault owner's client material. Project instructions and explicit task authorization govern execution.

## Included and optional references

The `website-build` skill depends only on the included Unslop skill and `Design/00 Framework/Product Interface Design Method.md`. Unslop's Markdown references, example images, scripts, citation and license are all included. Its image-generation or browser capability is supplied by the active client and is optional; report an unavailable capability honestly.

References to Strix skills name sibling skill folders, all included here. Example API schemas, tokens, application paths and `strix_runs/` reports are user inputs or runtime outputs, not missing template files. Strix CLI, Docker, LLM providers and managed cloud services require separate setup and authorization.

The Design framework mentions optional reviewers (`site-auditor`, `launch-red-team`) and tools such as HeroUI, 21st.dev, GSAP, Lenis and browser/performance tools. Those integrations are not bundled; use available equivalents to perform the stated review and record limits. Private design datasets and historic client builds are deliberately absent.

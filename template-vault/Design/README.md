# Design

Reusable interface design methods live in `00 Framework/`. Use the project-local `website-build` and `unslop` skills with these documents. Store new project-specific briefs, decisions and review findings in your own project records. Implementation and assets belong in the project repository.

This distribution omits the original owner's client builds, private reference libraries and personal taste logs. Public reference tools and libraries require their own access and license checks. The interface method adapts Damir Sokolovsky's Unslop under CC BY 4.0; attribution and license are retained in both Unslop skill folders.

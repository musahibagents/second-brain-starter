# Filing Rules

The primary subject determines location: identity and goals in me; relationships in people; organizations, projects and pipeline in ventures; reusable implementations/specifications in systems; actionable plans/offers in strategy; reusable ideas/research in knowledge; dated events in journal; source distillations in summaries. Preserve raw inputs separately in raw when needed, with provenance; do not silently rewrite them. inbox is temporary triage. _system contains operating rules, state and configuration references. Search first, use frontmatter, cite claims and link related canonical pages. Keep distinct ventures distinct. Create subfolders only when the corpus needs them. Folder names alone do not make data private or hidden in Obsidian.

# Notability Gate

Before creating an entity page ask whether it has future relevance, relates to active work, and has evidence beyond a passing mention. Signals include direct interaction with follow-through, repeated independent mentions, an active project role or explicit owner instruction to track it. Cold imports and one-off article names remain on the source/batch page. Transcript attendance alone is insufficient and garbled words are not identities. Start a justified new entity small, with a first sourced event explaining its relevance. Reassess when new evidence arrives; ask before merging, deleting or archiving.

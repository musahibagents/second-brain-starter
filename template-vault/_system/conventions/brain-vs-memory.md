# Brain Vs Memory

Route durable facts about people, projects and ideas into the appropriate wiki pages. Route active priorities, working preferences and operational corrections into _system/MEMORY.md with links to detail. Immediate task context belongs in the conversation; carry unfinished substantial work into _system/session.md. Memory is a compact index and operating state, not a transcript archive. A correction about a person updates that person; a correction about assistant behavior updates the operating rule. Both may apply. This distribution uses explicit files; no hidden memory service or automatic session capture is assumed.

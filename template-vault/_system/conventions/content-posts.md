# Content Posts

Use one canonical file per post under strategy/Content. Preserve draft versions separately from the exact published text. On confirmed publication record platform, URL/ID, timestamp/timezone, media, final copy and evidence of publication. Metrics are dated observations from actual tools or screenshots with source and metric definitions; never estimate them or copy numbers from another post. Keep multiple pulls for change over time and compare equivalent periods. Record edits as later events. A draft is not published and an old metrics pull is not current.

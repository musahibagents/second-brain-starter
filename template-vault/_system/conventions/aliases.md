# Aliases

Search names, handles and known variants before creating an entity. Use one canonical page, with YAML aliases for genuine alternative names. Prefer verified full names; never resolve a garbled transcript into a confident identity. Distinguish people who share a name using role/company evidence. Link aliases to the canonical page. A rename must preserve inbound references; merging existing pages needs approval and must retain both evidence histories. Do not invent aliases from speculation.

# Auto Audit

Review each substantive artifact against its brief and source evidence before declaring it complete. Check completeness, contradictions, accuracy, audience, readability and actionability. For interfaces inspect the rendered result at relevant viewports and correct visible defects, broken interactions, overflow and accessibility issues. For code use checks proportionate to the change. Repeat on changed portions; stop when acceptance criteria are met. Record what was actually checked and any remaining uncertainty. Do not claim a browser or integration check that was not run.

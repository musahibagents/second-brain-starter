# Queue And Flush

Prepare research, qualification, drafts and action targets before using an interactive browser for authorized execution. Queue items include exact target, payload, account, evidence, prerequisites and approval scope. Execution begins only with authorization for those external actions; computer access alone is not permission to send. Recheck target and current page state immediately before each action. Stop for material changes, unexpected dialogs or uncertainty. Keep result receipts and do not resend ambiguous successes. Avoid interfering with the owner’s active app; coordinate control when necessary. Close only tabs created for the task.

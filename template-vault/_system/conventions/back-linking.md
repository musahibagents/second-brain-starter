# Back Linking

Whenever a source page links a notable entity, add a meaningful reference back from the entity to the source event or evidence. Link related entities where a substantive relationship exists, not every name indiscriminately. Use canonical paths where titles collide. Avoid duplicate timeline entries and self-links. On rename update inbound links. Missing targets should be resolved through aliases and notability before creating stubs. During maintenance check dangling links, orphaned important pages and links whose display names disguise the wrong target.

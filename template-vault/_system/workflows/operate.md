# Daily operation
Brief: read current priorities, commitments and recent journal; show concrete next actions and blockers with source links. Dates missing from records remain unknown.
Debrief: distill what happened, decisions, evidence, commitments, owners and dates; update entities and journal. Separate proposed actions from agreed actions.
Research: define question; search existing knowledge; gather current primary sources when needed; record dates, citations, findings, uncertainty and implications. Never invent tool access. Ask before paid services.
Follow-up: reconcile commitments against evidence; draft necessary messages; owner authorizes sending.
Plan: define desired result, scope, constraints, dependencies and completion criteria. Proceed with work the owner authorized; distinguish exploration from implementation instructions.
Handoff: save current state, decisions, changed paths, remaining work and verification limits in session.md. Never store credentials.

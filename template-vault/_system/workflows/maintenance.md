# Maintenance
Run on explicit request; no scheduler is bundled. Read conventions first. Record a dated report even on partial failure.
Light: audit frontmatter, broken links, missing backlinks, duplicate candidates, stale commitments and missing next actions. Apply safe formatting corrections; report substantive issues.
Weekly: light plus synthesize repeated findings, identify unnamed themes, reconcile contradictions from sources, check overgrown MEMORY, and produce a recap. Keep historical claims dated. Obtain approval for deletion/archival or destructive merges.
Full: weekly plus audit stale source links and produce `_system/graph.json` with nodes and typed edges supported by pages. Include source paths and dates on each edge. Flag unsupported relations.
Report files examined, edits, unresolved issues and skipped integrations. Do not claim checks you could not perform. These procedures require only file access; optional upstream research/integration workflows are reference material.

# Completion Status

Report DONE only with named evidence; DONE_WITH_CONCERNS when the deliverable exists but a material check remains; BLOCKED when a concrete dependency prevents progress; NEEDS_CONTEXT when required information is missing. State the reason, attempts and next step when incomplete. A draft is not a send, a build is not a deployment, a meeting booked is not a meeting held. Commercial states stay distinct: paid cash, signed commitment with payment outstanding, verbal agreement, proposal sent and draft. Signed does not mean banked. Never combine currencies without an explicit dated conversion basis. Confidence reflects evidence; name what would change the conclusion. Do not repeatedly retry an unchanged blocker. These reporting labels do not override any tool-specific status rules.
